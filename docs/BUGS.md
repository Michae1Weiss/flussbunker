# Bugs

* **Submarine line of sight:** Submarine fires torpedoes through obstacles when enemy ship is in one line with submarine.
* **Submarine rotation:** Submarine placed in a corner keeps the previous tile's rotation instead of rotating towards its firing line.

# Gameplay

* **Ritterkreuz:** Currently seems impossible within 12 waves because torpedo reload is too slow & too little waves.
  * Try firing all torpedoes as a fast salvo with minimal delay between shots.
* **Submarine upgrades:** Let the player manually upgrade submarines by clicking an upgrade button/arrow.
  * Upgrades could change the submarine to a newer model instead of increasing veterancy.

# Combat

* **Turrets:** Slowly rotate towards enemies instead of instantly aiming.
* **Predictive aiming:** Aim at where the enemy is expected to be.
* **Accuracy:** Add some randomness so turrets can occasionally miss or hit another ship.
* **Firing delay:** Add time for rotating → targeting → firing.
* **Enemy collisions:** Ships should not be able to pass through each other.

# Visuals

* **River:** Current square shape looks ugly. Make it more natural/organic.
